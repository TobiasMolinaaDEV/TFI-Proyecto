## ¿Nosotros? - OficiosYa
Nuestra mision es solucionar una problematica que actualmente no a sido atacada por ninguna aplicacion o 
prototipo actualmente y es facilitar tanto para el usuario final y las personas que desean trabajar en oficios 
una manera sensilla y fiable tanto para contratar como para ofrecer sus trabajos.

## ¿Tecnologias utilizadas?

utilizamos 2 principales tecnologias HTML para el maquetado de nuestra web y css para agregarle una parte de estilos.
